# Дополнительная аналитика — 17.10.2026

Обязательный график позиций сохранён. Дополнительно доступны два сценария:

- **История цен** — переключатель «Позиции / Цены» для тех же артикулов, периода и глубины. Цена берётся из сохранённого ответа WB, в рублях с точностью до копейки. Недоступная цена и отсутствующий товар дают пропуск; нулевая цена не теряется.
- **Изменения выдачи** — раскрываемый блок сравнения двух последних полных снимков выбранного периода. Положительное изменение означает подъём. На графике 12 наибольших изменений, в таблице и CSV — все общие, вошедшие и вышедшие артикулы. Вход и выход из топа не получают вымышленную позицию или числовую разницу.

Неполные и ошибочные снимки не используются для сравнения всей выдачи. Глубина, регион и поисковая фраза должны совпадать. Графики не создают новые наблюдения и не меняют историю.

CSV истории теперь содержит сохранённые характеристики: цену в копейках, рейтинг, отзывы, доставку, продавца и название. Статус снимка сохранён в `run_status`.

- Проверены все 70 фраз, оба графика истории, сравнение снимков, фильтры периода, выгрузки и мобильный экран 390 × 844. Пустые периоды и неполная выдача обработаны отдельно.

[Проверка от 04:15 МСК](verification_analytics_2026-10-17/moscow_region.json) сохраняет только параметры запроса и код региона; IP и подпись сессии исключены.

Повторить на VPS:

```bash
docker compose exec -T dashboard python -m scripts.verify_moscow_region
```

Код 0 — конфигурация совпала с ответом WB; код 2 — расхождение или проверка недоступна. Проверка не меняет регион и не пишет наблюдения в SQLite.
