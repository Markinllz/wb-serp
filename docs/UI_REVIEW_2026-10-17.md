# Интерфейс и проверка — 17.10.2026

Панель сокращена до трёх разделов: «Позиции», «Товары», «Сборы». На первом экране — выбранная фраза, время снимка, три показателя и график. Убраны градиенты, эмодзи, повторный заголовок и постоянные пояснения. Справка доступна в блоке «О данных».

## Решения

| Проблема | Изменение |
|---|---|
| Декоративный заголовок отодвигал данные вниз | Заголовком стала выбранная поисковая фраза |
| Подсказки повторяли названия элементов | Короткие подписи; пояснения только для ограничений и статусов |
| Период воспринимался как фильтр всей панели | Даты явно относятся к графику; таблица показывает последний снимок |
| Редактирование диапазона дат работало нестабильно | Два независимых поля; проверка пустого и обратного периода |
| Шаг оси скрывал подписи при позициях 1–3 | Целочисленный шаг подбирается по диапазону данных |
| Короткая выдача была недоступна в интерфейсе | Таблица, поиск, график и CSV включают валидные `partial` |
| Отсутствие в неполной выдаче можно принять за потерю позиции | Неполные точки отмечены ромбом; CSV содержит `run_status` |
| В таблице показывалось техническое `None` | Недоступные характеристики отображаются прочерком, в CSV остаются пустыми |
| Ошибку дублей штатный worker не повторял | Один повтор с первой страницы после паузы; обе попытки сохраняются |

Основа решений: [GOV.UK — короткие тексты интерфейса](https://www.gov.uk/service-manual/design/writing-for-user-interfaces), [NN/g — визуальная иерархия](https://www.nngroup.com/articles/visual-hierarchy-ux-definition/). Реализация таблиц и выгрузок сверена с документацией [Streamlit 1.54](https://docs.streamlit.io/1.54.0/develop/api-reference/data/st.dataframe) и [download_button](https://docs.streamlit.io/1.54.0/develop/api-reference/widgets/st.download_button); осей — с [Plotly](https://plotly.com/python/reference/layout/yaxis/).

## Проверено

- Автотесты: **159 PASS**, один тест настоящего Chromium отдельно пройден в Docker без внешней сети. Ruff — PASS. Среди тестов есть полный цикл 70 × 200 на контролируемых HTTP-ответах; он не считается живым сбором WB.
- Свежий штатный сбор в **03:52–03:53 МСК**: `постельное белье 2 спальное` — 200 товаров, `dr. hygge` — 106. WB сообщил `total=106`; второй запуск корректно завершился как `partial` с кодом 2. В более ранней серии было 114 товаров.
- Chromium открыл все **70 запросов**; для каждого количество товаров в интерфейсе совпало с SQLite. Проверены поиск по артикулу, выбор нескольких товаров, фильтры дат, обновление панели и CSV.
- Товар, отсутствующий в последнем полном снимке: позиции **7 → 7 → пусто**, линия прерывается. Неполная выдача доступна в таблице и экспорте; её исторический каталог содержит 116 артикулов.
- Desktop 1366 × 1050 и mobile 390 × 844: горизонтального переполнения страницы нет. Таблицы прокручиваются внутри своего блока. Ошибок JavaScript и внешних запросов панели нет.
- Миграция v2 → v3 дополнила каталог. Все прежние **152 запуска и 28 881 наблюдение** сохранены побайтно на уровне сериализованных строк; контрольные суммы совпали. SQLite: `integrity_check=ok`, нарушений внешних ключей нет.
- После двух новых сборов: 154 запуска, 29 187 наблюдений. Последние снимки содержат **69 × 200 + 106 = 13 906 позиций**. Браузерная проверка не меняет базу.

## До публичного запуска

Нужны деплой на целевую VPS, проверка доступа к WB с её IP и внешний HTTPS. Соответствие `dest=1259570991` конкретному адресу и персональная цена покупателя требуют сверки на сайте. Доставка в текущем ответе отсутствует. Многосуточная стабильность ещё не подтверждена. Строгие 70 × 200 не подтверждены: источник возвращает меньше 200 товаров для одной фразы.

При запуске актуального collector миграция выполняется автоматически. Перед обновлением существующей базы создайте резервную копию. Панель открывает SQLite только для чтения. Локальный фоновый collector после проверок остановлен; панель доступна на http://127.0.0.1:8501.
