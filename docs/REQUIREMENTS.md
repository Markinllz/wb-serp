# Требования и состояние

| Требование | Реализация |
|---|---|
| 70 исходных фраз | `config/queries.txt`, дословное сохранение формулировок |
| Управление запросами дополнительно к ТЗ | Свои фразы, пауза, удаление и восстановление; исходный набор сохранён; пользователь управляет активностью каждой фразы |
| Настраиваемая глубина выдачи | Пагинация, проверка уникальности `nm_id` и непрерывности позиций, по умолчанию 200, настройка 1–1000 в интерфейсе или начальное значение `WB_TOP_N` |
| Сбор раз в час | Отдельный worker, запуск на границе часа, ограниченные повторы |
| Фиксированный город | Москва, подтверждённый `dest=1259570991`; защита от смешения регионов |
| История фразы, времени, позиции и артикула | SQLite WAL, атомарная запись снимка, сохранение прежних запусков |
| Цена, рейтинг, отзывы, доставка, продавец | Цена напрямую из отображаемой карточки WB; доступные характеристики; неизвестные значения остаются пустыми |
| Выбор фразы и ранее найденных артикулов | Поиск по всей истории, включая неполные снимки |
| Интерактивный график позиций | Несколько товаров, период, позиция 1 сверху, разрывы при отсутствии данных |
| Таблица и выгрузка | Последняя выдача, характеристики выбранных товаров и CSV |
| Доступный веб-интерфейс | Docker, Caddy, HTTPS и пароль |
| Инструкция запуска и исходники | README, Compose, тесты, схема архитектуры |

Дополнительно доступны карточки выбранных товаров со ссылками WB, история цен, сравнение двух полных снимков и Grafana с мониторингом приложения и сервера. Для сбора полного исходного набора все 70 запросов ТЗ должны оставаться включёнными.

В проверенном проходе 17 октября 2026 года собраны все 70 фраз: 69 полных снимков и одна выдача из 106 товаров, всего 13 906 валидных наблюдений. Позиции и артикулы сверены с SQLite; прежняя история сохранена без изменений. Проверены все 70 фраз в панели, CSV, графики, мобильная ширина, HTTPS и восстановление резервной копии.

## Ограничения источника

У фразы `постельное белье евро вареный хлопок dr. hygge` WB возвращает меньше 200 товаров. Программа сохраняет настоящую короткую выдачу, не дополняя её и не меняя запрос. Строгий результат 70 × 200 не подтверждён.

Браузерный сбор получает подпись доставки через функцию отображения самого WB и переводит её в календарную дату Москвы. Сегодня — 0 дней, завтра — 1. Неизвестные форматы остаются пустыми; старая история не переписывается. Цена на WB читается из отрисованных карточек выдачи и сопоставляется по артикулу. Условие «с WB Кошельком» записывается только при наличии соответствующей подписи. Обычная цена из ответа WB хранится отдельно; старая история не пересчитывается. Внутренний поисковый интерфейс WB может менять правила доступа и формат ответа.
